# Now 已确认决策

状态：已确认（2026-08-31）。  
本文件记录用户同意“先做 Now”后冻结的产品决策。

## NOW-D1. 首版定期事项只支持固定日历节奏

- 类型：Plan 或 Errands。
- 节奏：每天，或每周选择一个及以上星期。
- 字段：标题、开始日期、可选默认开始时钟、可选默认结束时钟。
- 暂不支持自然语言规则、任意 RRULE、按完成日期重复、结束日期、系统提醒、外部日历同步。

## NOW-D2. 模板与每期实例分离

每个命中的日期生成一个普通、独立的实例。完成某一期不停止系列；编辑模板只影响尚未生成的未来实例，过去和已经生成的实例保持不变。

## NOW-D3. Plan 与 Errands 沿用各自日界语义

- 定期 Plan 自动出现在命中日的 Plan；当天未完成，按既有规则回到 To Do。下一期仍独立出现，不静默合并。
- 定期 Errand 自动出现在命中日的 Errands；当天未完成，按既有规则作废，不进入 To Do。

## NOW-D4. 系列支持暂停、恢复与停止

- 暂停可恢复，暂停期间不生成且恢复后不补发。
- 停止不可恢复。
- 暂停或停止都不删除已经生成的今天实例和历史实例。

## NOW-D5. 每天有一次显式的规划完成状态

当天初始为“尚未规划”。打开规划工作表只是前端的“规划中”，不代表完成；只有用户点击“今天计划已就绪”才记为已规划。已规划后仍可手工调整，不重新强制打开流程。

规划工作表展示：今天的定期事项、昨天回到 To Do 的任务、目标日已到或逾期的任务、其他 To Do、未来七天摘要。除已经承诺自动出现的定期实例外，候选任务都由用户主动加入今天。

## NOW-D6. Agent 以当天首次规划为主，并保留全局入口

Agent 一般在当天首次规划时使用，规划工作表保留“让助手整理”入口。为了随时可用，顶部导航常驻“计划助手”按钮；两个入口展开同一个默认关闭的侧边栏，并按当前页面传入今天、To Do 或指定日期上下文。Agent 只由用户主动发送，执行成功不等于计划已就绪，仍需用户确认。

## NOW-D7. Agent 展示结构化改动回执

执行后展示计划对象的结构化变化，例如新增 Plan、从 To Do 加入今天、移回 To Do、更新标题或时钟。原始 stdout/stderr 只作为可折叠技术输出，不作为回执，也不保留聊天记录。

## NOW-D8. 用药场景不承诺提醒能力

“每天吃药”可建为定期 Errand，但产品必须明确：本应用不发送系统通知或闹钟，不应作为唯一的用药提醒工具。

## NOW-D9. 已停止系列允许删除，但保留历史来源

删除是管理视图中的软删除，只允许用于已经停止的系列。进行中或已暂停系列必须先停止；删除后系列不再出现在定期事项列表或 Agent 上下文，但已经生成的 Plan / Errand、occurrence 账本及其系列来源均保留。

## NOW-D10. 日常启动命令命名为 local-todo

`local-todo` 无参数时负责确保本机服务已经就绪并打开网页：服务未运行则在后台启动，已运行则直接复用。`local-todo open` 是同义的显式形式，`local-todo serve` 保留前台运行模式。内部 Python 包名与原有 `local-planner` 命令不重命名，继续兼容。
