# 第一批用户的使用体验

2026-09-26 用户授权补齐删除撤销、应用内备份恢复、首次使用提示和 Agent 环境检测，并明确要求页面简洁、操作一目了然。本轮覆盖原有文档中备份及引导的后置范围，不扩大同步、提醒、账户或自动排程范围。

## 页面与操作

- 主导航新增「设置」，主题选择移入设置。桌面菜单提供 Cmd+, 打开设置。
- 今天页使用一条可关闭的入门提示，解释回车添加、勾选完成、计划回待办和零碎事项不跨日。关闭后按当前浏览器保存；设置中随时可查看简短说明。
- 「整理今天」缩为文字入口，不占用一整张提示卡。
- 设置采用单列：数据与备份、可选的计划助手、外观。备份列表和高级助手命令默认折叠。

## 删除后撤销

- 今天、待办、零碎事项和已停止的定期事项删除后显示底部「撤销」提示，30 秒后收起。连续删除可逐项撤销，界面最多保留 5 条待撤销提示。
- 服务端记录在本次运行期间有效，最长 5 分钟。应用关闭后不保留；没有全局编辑历史。
- 撤销通过领域命令恢复单个实体及其可写日安排，不回滚整库，不覆盖之后新增或修改的其他事项。排序位置被占用时追加到列表末尾。
- 跨日或封印后不重写历史；恢复备份后，此前的撤销记录失效。撤销删除定期事项只恢复它的已停止状态。

## 本地备份与恢复

- 每天第一次通过应用访问计划数据时自动生成一份本地备份，最多保留最近 14 份自动备份。手动备份、升级前备份和恢复前备份不自动清理。
- 应用未运行时不创建备份。备份在数据目录的 backups 文件夹，仍属于本机数据；可通过「下载」另存。
- 设置支持立即备份、下载、选择外部备份文件和恢复。桌面端使用原生文件选择与保存窗口。
- 备份包含数据库中的计划、定期事项、历史及完成状态；不包含外部助手登录信息、启动器配置和主题。
- 导入上限 32 MB，只接受已知 Local Planner SQLite 结构。验证完整性、外键、迁移版本、表和触发器结构以及时区；旧版本先在临时副本中迁移和执行领域结转。
- 恢复需要用户在应用内明确确认替换当前事项和历史。先成功保存当前数据库，再将检查后的副本写入现有数据库连接；采用 SQLite backup API，兼容 WAL 和其他空闲窗口的数据库连接。
- 恢复时持有助手执行租约和计划锁，任何应用窗口中正在运行或暂停的助手都会阻止恢复，提示先停止助手。
- 新安装空数据库不再产生无意义的升级前备份；现有数据库升级仍会保留迁移前备份。

## 可选助手

- 新用户使用 Codex 或 OpenCode 工具自己的默认模型，不包含开发者的个人 provider 或指定模型。已有启动器不被覆盖。
- 设置支持环境检测、编辑、新增和移除助手。面板遇到未安装或未登录状态时显示「连接助手」入口，并禁用发送。
- 检测不发送模型请求、不读取凭据文件、不执行用户命令模板。工具存在与账户可用是不同状态；自定义工具只报告安装情况。
- Codex 仅执行 `codex login status`，本机账户已登录不代表模型或额度验证成功；输出不会返回到界面。参考 [OpenAI Docs：Developer commands](https://learn.chatgpt.com/docs/developer-commands)。
- 使用助手前说明指令和计划上下文会交给所选外部助手及模型服务。保留原有暂停、恢复、修改指令继续和停止能力。

## 验证与后续

- 使用隔离数据库验证撤销、排序冲突、跨日只读、恢复前备份、下载导入、旧版本迁移、文件拒绝和助手执行互斥。
- 助手检测使用测试可执行文件验证；不向真实模型发送指令。
- 签名公证、最低系统版本拓展、公开下载页面和自动更新仍属后续分发工作，未在本轮开启。
