# 第一批用户的使用体验

2026-09-26 用户授权补齐删除撤销、应用内备份恢复、首次使用提示和 Agent 环境检测，并明确要求页面简洁、操作一目了然。本轮覆盖原有文档中备份及引导的后置范围，不扩大同步、提醒、账户或自动排程范围。

## 页面与操作

- 主导航新增「设置」，主题选择移入设置。桌面菜单提供 Cmd+, 打开设置。
- 今天页使用一条可关闭的入门提示，解释回车添加、勾选完成、计划回待办和零碎事项不跨日。关闭后按当前浏览器保存；设置中随时可查看简短说明。
- 「整理今天」缩为文字入口，不占用一整张提示卡。
- 2026-09-28 用户要求精简首页并重设计设置。移除今天及日期页的完成进度栏；助手输入框上方的标题、当前页面与收起文字，以及下方快捷键、隐私说明与设置入口一并移除。再次点击顶部「计划助手」或按 Esc 收起；发送按钮的悬停提示保留快捷键，执行状态、错误与暂停控制按需显示。
- 设置改为固定分区导航和独立内容区：外观、计划助手、快捷键、数据与备份、使用说明、关于作者。打开即可看到全部六个入口，点击切换内容；只有右侧长内容滚动。窄窗口导航改为两行，全部入口仍可见。
- 设置分区支持方向键、Home / End 切换；切换保留未保存的助手配置草稿，原生菜单直接定位使用说明、作者或助手连接区。备份列表和高级助手命令默认折叠。

2026-09-27 用户要求补充使用说明、关于作者及其 GitHub 头像。

- 「使用说明」与「关于作者」各自作为设置分区，从固定导航直接选择，内容无需再次展开。
- 使用说明覆盖添加与完成、编辑与删除撤销、事项分类、历史只读、助手暂停及修改指令、备份迁移、常用快捷键。明确暂停原进程与修改指令后开始新执行的区别。
- 关于区显示应用版本、简短介绍、作者 Yuchen An（@King-A23）及 GitHub 主页。头像来源于该账号的公开头像，随应用打包；查看作者信息不发起外部网络请求，点击主页才打开 GitHub。
- 版本由前端 package.json 在构建时注入。当前仓库未公开，不提供公开源码或 Issues 入口，也不宣称开源。
- macOS「帮助 → Local Planner 使用说明」与「关于作者」直接切换到对应分区；应用菜单的「关于 Local Planner」使用同一份内容。
- 应用内简要说明本地存储、无云同步，以及使用助手时向所选工具及模型服务传递上下文的行为。

## 删除后撤销

- 今天、待办、零碎事项和已停止的定期事项删除后显示底部「撤销」提示，按用户 2026-09-28 要求，改为 3 秒后自动收起。连续删除可逐项撤销，界面最多保留 5 条待撤销提示；每条都从删除成功起独立计时，旧提示不会重新获得 3 秒。点击撤销后，即使提示到期，恢复请求也会继续完成。
- 服务端记录在本次运行期间有效，最长 5 分钟。应用关闭后不保留；没有全局编辑历史。
- 撤销通过领域命令恢复单个实体及其可写日安排，不回滚整库，不覆盖之后新增或修改的其他事项。排序位置被占用时追加到列表末尾。
- 跨日或封印后不重写历史；恢复备份后，此前的撤销记录失效。撤销删除定期事项只恢复它的已停止状态。

## 本地备份与恢复

- 每天第一次通过应用访问计划数据时自动生成一份本地备份，最多保留最近 14 份自动备份。手动备份、升级前备份和恢复前备份不自动清理。
- 应用未运行时不创建备份。备份在数据目录的 backups 文件夹，仍属于本机数据；可通过「下载」另存。
- 设置支持立即备份、下载、选择外部备份文件和恢复。桌面端使用原生文件选择与保存窗口。
- 备份包含数据库中的计划、定期事项、历史及完成状态；不包含外部助手登录信息、启动器配置和主题。
- 导入上限 32 MB，只接受已知 Local Planner SQLite 结构。验证完整性、外键、迁移版本、表和触发器结构以及时区；旧版本先在临时副本中迁移和执行领域结转。
- 恢复需要用户在应用内明确确认替换当前事项和历史。先成功保存当前数据库，再将检查后的副本写入现有数据库连接；采用 SQLite backup API，兼容 WAL 和其他空闲窗口的数据库连接。
- 恢复时持有助手执行租约和计划锁，任何应用窗口中正在运行或暂停的助手都会阻止恢复，提示先停止助手。
- 新安装空数据库不再产生无意义的升级前备份；现有数据库升级仍会保留迁移前备份。

## 可选助手

- 2026-09-28 用户要求修复中文输入法确认英文时误发送，并单独支持快捷键设置。设置新增「快捷键」区，可选 Enter 发送（默认，Shift+Enter 换行）或 macOS ⌘+Enter / 其他平台 Ctrl+Enter 发送（Enter 换行），修改立即同步到桌面主窗口，按本机浏览器保存。该偏好不包含在数据库备份中。
- 输入法回车确认仅提交当前文字，不发送助手指令；覆盖 compositionend 先于 keydown 的 macOS WebKit 事件顺序、原生输入法标志和长按回车。松开确认键后，下一次发送快捷键正常生效。输入法取消键不会关闭助手面板。

- 新用户使用 Codex 或 OpenCode 工具自己的默认模型，不包含开发者的个人 provider 或指定模型。已有启动器不被覆盖。
- 设置支持环境检测、编辑、新增和移除助手。面板遇到未安装或未登录状态时显示「连接助手」入口，并禁用发送。
- 检测不发送模型请求、不读取凭据文件、不执行用户命令模板。工具存在与账户可用是不同状态；自定义工具只报告安装情况。
- Codex 仅执行 `codex login status`，本机账户已登录不代表模型或额度验证成功；输出不会返回到界面。参考 [OpenAI Docs：Developer commands](https://learn.chatgpt.com/docs/developer-commands)。
- 在设置的助手连接说明与关于区说明指令和计划上下文会交给所选外部助手及模型服务。保留原有暂停、恢复、修改指令继续和停止能力。
