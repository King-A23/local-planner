# 已确认决策

只记录用户已经拍板的内容。未出现在这里的，仍是待确认。

记录日期：2026-08-30

## D1. v1 主场景：写今日计划

第一版要赢的日常是：早上或晚上把今天要做的事排好，当天跟着清单走。

长期任务要存在，但不是第一版的主界面和主节奏。

## D2. 产品形态：本机网页

第一版用浏览器打开本机页面（localhost）。数据留在本机。

不作为 v1 必达：独立 macOS 应用、终端、手机端。

## D3. 长期任务与今日计划：库存 → 今日抽取

长期任务是库存。每天把几条放进今日计划。没抽进今天的，当天不出现、不打扰。

这对应发现简报里的关系选项 B（当天是长期任务的投影），而不是两套完全独立清单，也不是第一版就做项目树。

## D4. 当前习惯：纸质 / PDF 日计划表

现在用纸质或 PDF 计划表记一天。本机已有 Daily Planner 纸模：日期 + To-Do List + Quick Errands + 06:00–23:00 小时表。

软件要补的，是纸张不容易做的那一半：长期任务库存、跨日找回、不必每天手抄。

具体痛点已在 D8 确认。

## D5. 第一版日视图：今日待办 + 零碎差事

继承纸模左栏：正经待办和买东西 / 交表 / 跑腿分开列。

第一版**不做** 06:00–23:00 小时时间块。

## D6. 未完成默认回到长期库存

今天没做完的事项，从「今天」拿掉，回到库存。第二天不会自动堆上来。要继续做，再重新抽到那天。

## D7. v1 不同步，本机即可

数据放这台电脑。第一版不做 iCloud / 网盘同步，也不做多设备。备份可以后做。

## D8. 核心痛点：过去的日子很难翻、很难找

纸上做完就叠起来或丢掉。想知道某件事哪天做过、还欠什么，翻起来很烦。

软件相对纸张要赢的，不只是「能记长期任务」，还包括「过往某一天还找得回来」。v1 范围见 D10。

## D9. 零碎差事当天作废

差事默认只属于今天。没做完不会进入长期库存。真正要跨日的事，记成正经待办。

## D10. v1 能按日期翻开过去某一天

第一版除了「今天」，还要能点开过去某天，看见当时的计划。不做全文搜索（可后置）。

## D11. 同一条长期任务可跨日抽取，直到勾完成

研究、竞赛、代码这类事可以今天抽、没做完回库存、改天再抽，始终是同一条，直到勾完成。

## D12. 今天直接写下正经待办 = 新建并立刻放进今天

不必先去库存。当天做完就留在那天的历史上；没做完，按 D6 进入库存，改天还能再抽。

## D13. 过去某一天只读

历史是那天的记录。不能在过去的日子上补勾、改内容或补抽。勾选和改计划只发生在今天（以及尚未到来的未来某天）。

## D14. v1 能把任务排到未来某一天

除了库存和今天，可以把正经待办指定到未来某天。那天一到，这些任务自动出现在当天计划里。未完成仍按 D6 回到库存，不会自动顺延到下一天。
