# 交互打磨：第一轮

2026-09-28。用户确认先推进中、较低难度改动，重点改善交互与操作手感；本轮落实讨论中的拖动排序、搜索、事项备注、macOS 全局快速录入。此轮是对早期冻结范围的明确增补，不包含项目树、同步、手机端、提醒或自动排程。

## 实现范围

- **列表排序**：今天及未来日期的计划、零碎事项支持拖动把手，显示插入位置；聚焦把手可用 Option / Alt + 上下键调整。手动排序持久保存，并优先于时间字段。手动排序后出现「按时间」，可恢复原有时间优先规则。历史日期只读，封存时保留当时的排序方式。待办保持原有收集顺序。
- **搜索**：顶部放置一个搜索图标，⌘ / Ctrl + K 唤出。匹配标题和备注，不区分英文大小写，支持空格分隔关键词。范围为待办、今天和未来已创建的未完成事项，不预生成无限重复事项、不搜索完成及历史记录。方向键选择、回车定位并高亮目标；结果最多展示 50 项并提示总数。
- **备注**：点击事项标题打开简洁详情窗口，标题与纯文本备注一起保存，备注最多 10000 字。⌘ / Ctrl + Enter 保存；保存失败保留草稿；有未保存内容时，关闭操作显示就地的放弃入口。历史仅查看。备注随待办、排期、结转、撤销、备份保留，历史使用当天快照。若其他窗口或 Agent 改动过同一标题/备注，拒绝用旧草稿覆盖。已有 Agent 上下文返回备注；本轮不新增 Agent CLI 备注写入命令。
- **全局快速录入（macOS）**：默认 ⌃ ⌥ Space，独立原生小窗口，选择待办或今天，Enter 添加并收起；Esc 收起并保留本次草稿。添加至今天使用服务端当前日，防止过午夜后写入旧日。提交期间防止重复添加，错误保留输入。设置支持 ⌃ ⌥ Space / ⌃ ⇧ Space / 关闭；冲突时提示并保留已有可用设置。文件菜单也可打开。应用运行时有效，关闭主窗口后留在 Dock，⌘ Q 退出后失效；不引入登录启动项或独立守护进程。

## 交互与数据约束

- 主界面只增加搜索图标；备注按需打开、拖动把手悬停/聚焦时出现。保留此前圆润输入框和设置分区布局。
- 中文输入法确认回车与提交分开处理。列表新增复用已有 WebKit 组合输入保护；原生快速录入走系统文本输入。
- 无新前端依赖。数据迁移 007 增加备注、快照和按日排序偏好；从已有数据库升级前自动生成 pre-migrate 备份，封存触发器仍生效。
- 排序冲突刷新列表，不移动到另一列；搜索不修改事项；详情编辑错误不丢弃草稿。
