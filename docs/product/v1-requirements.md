# v1 需求冻结稿

状态：已冻结（2026-08-30，用户确认继续）。  
依据：[decisions.md](decisions.md) D1–D14。  
工作名：Local Planner。正式名未定。

这是产品需求，不是设计文档，也不是实现方案。

---

## 1. 一句话

本机网页上的个人日计划工具：每天写出今天要做的事，长期任务放在库存里，需要时抽到今天或排到未来某天，并且能只读翻回过去某一天。

## 2. 给谁用

先给使用者自己：同时有课业、实验室、竞赛和多个代码项目，现在用纸质 / PDF 日计划表，痛点是过去的日子很难翻、很难找。

## 3. 第一版必须做到

1. **打开就是今天。** 几分钟内写下或选出今天要做的正经待办，并另列零碎差事。
2. **长期任务有库存。** 突然冒出的跨日事项可以记进去，不必出现在今天。
3. **从库存排到某一天。** 可以抽到今天，也可以指定到未来某天。没排期的当天不露面、不打扰。
4. **未来某天一到，已排任务自动出现在当天计划里。**
5. **第二天是干净的。** 没做完的正经待办回到库存；没做完的差事作废。不会自动堆到下一天。
6. **同一条待办可以跨很多天被抽到某天**，直到勾完成。
7. **能按日期打开过去某一天**，只读查看当时的计划和勾选结果。
8. **只在这台电脑上跑**，浏览器打开 localhost，v1 不同步、不上云账号。

## 4. 第一版明确不做

- 小时时间块 / 电子课程表 / 外部日历同步
- 手机端、macOS 独立应用、终端
- 多设备同步、云账号
- 项目树、标签体系、优先级系统、习惯打卡
- 全文搜索历史、提醒、AI 自动排程
- 多人协作
- 改写已经过去的某一天

## 5. 三个工作对象

| 对象 | 含义 | v1 规则 |
| --- | --- | --- |
| 正经待办 | 值得跨日的任务 | 可放库存；可排到今天或未来某天；没做完回库存；完成前可反复排期 |
| 零碎差事 | 只属于某一天的小事 | 只出现在那天；没做完当天作废；不进库存 |
| 某一天 | 一张日计划 | 今天和未来某天可写；过去的天只读 |

已确认的操作语义：

- 在「今天」上直接写下一条正经待办，等于新建任务并立刻放在今天。当天没做完，它进入库存。
- 也可以只写进库存、不排到任何一天。
- 可以把库存里的任务排到今天，或排到未来某一天。
- 差事只能写在某一天，没有库存入口。
- 过去的天只用来翻看，不能补勾或改计划。

## 6. 主路径

1. **写今天：** 打开应用 → 看到今日日期 → 写下待办 / 从库存抽取 / 写下差事 → 当天按清单勾选。
2. **记长期：** 想到一件还不定哪天做的事 → 写入库存 → 今天不被它打乱。
3. **预排未来：** 知道某件事要在周四做 → 把它排到那天 → 周四打开时它已在当天计划里。
4. **跨日推进：** 某条库存任务再次被排到某天 → 仍是同一条 → 做完才从库存消失。
5. **翻历史：** 选一个过去的日期 → 只读看到那天的待办、差事和勾选结果。

## 7. 成功标准

- 早上能在短时间里得到一份可执行的今天，而不必先翻完整条长期清单。
- 库存里的事找得到；没排到今天的事不会出现在今天。
- 能提前把任务放到未来某天；那天到来时不必再手抄。
- 新的一天不会被昨天的未完成项自动堵住。
- 任意过去一天的计划还能打开，且不会被事后改写。
- 关掉浏览器再打开，数据还在这台电脑上。
