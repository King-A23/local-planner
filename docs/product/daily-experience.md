# 日常体验打磨与助手执行控制

状态：2026-09-26 用户授权开发。目标是先把自己的日常使用打磨顺畅，保持简洁、容易上手。

## 本轮范围

- 界面用语统一为今天、待办、计划、零碎事项、定期事项。目标日期只作参考；安排到某天才进入那一天。
- 打开应用直接看到今天。通过「整理今天」主动进入已有规划流程，替代 Now 需求中未规划时自动进入工作表的行为。候选分组、日界和历史只读继续由领域层决定。
- 任务行突出勾选、标题和已设置的时间；时间编辑、移回待办、删除收进可用键盘操作的更多菜单。默认纸墨主题减轻背景装饰。
- 当前可写日或待办页支持 Cmd+N 聚焦新增输入；桌面其他页面的「新增事项」回到今天。回车保存后可继续录入，Esc 清空未提交内容。新增期间阻止重复提交，不清除网络等待期间另写的新内容。

## 助手控制

用户明确选择「暂时挂起当前执行，之后从原处继续」，并补充需要调整 prompt。

- 执行状态由本地服务保存，页面刷新、切页或收起面板不会丢失当前执行。收起后顶部仍显示执行中或已暂停。
- 暂停挂起本次本机进程组；继续恢复同一组。暂停时长不计入执行超时。
- 暂停前先获得计划库的进程锁，避免挂起正在保存计划的 CLI。短时间无法获得锁时提示稍后再试，不假报暂停。
- 已发出的远端模型请求可能继续运行；暂停不等于暂停服务端计算或计费。
- 暂停后可以修改指令。内容不变时「继续执行」恢复原进程；内容改变时「按新指令继续」结束旧执行，保留已有改动，重新读取当前计划，再启动新执行。沿用原执行的页面和日期上下文，不把新指令注入任意 CLI 的现有会话。
- 停止立即结束本次进程组，保留已经提交的改动，给出停止状态和可确认的变化。失败和停止均不承诺回滚。
- 同一数据目录只允许一个受管理的助手执行；重复请求复用同一次执行。旧同步运行接口继续兼容。
- 草稿和助手选择在本地保存。暂停期间输入区可编辑，技术输出默认折叠，发送不会自动清空原话。
- 2026-09-28 按用户要求恢复网页端的圆润胶囊输入框，两端使用同一套样式。短指令为一行，手动换行或长文字自动展开，删回短内容后收起；窗口宽度变化时重新计算，高度达到上限后在输入区内滚动。保留 Enter 发送、Shift+Enter 换行及中文输入法确认保护。
- 关闭应用会结束正在运行或暂停的助手，不支持跨应用重启恢复进程。运行回执仅在本次服务生命周期内保留最近 20 次，不是聊天历史。
