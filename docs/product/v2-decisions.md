# v2 已确认决策

只记录本轮用户已经拍板的内容。未出现在这里的，仍是待确认。

记录日期：2026-08-31

## V2-D1. 三块需求都定，实现先做 Agent CLI

v2 范围同时包含：Agent CLI、可选时间属性、自然语言窗口 + 用户定义 agent 分组。

开发顺序：CLI → 时间 → 窗口。窗口依赖 CLI。

## V2-D2. To Do 日期 = 目标日，仍留在 To Do

给 To Do 填日期，任务不会自动变成那天的 Plan。要进某一天的 Plan，仍用现有「排到某天」。

## V2-D3. Errands 与 Plan 同一套可选时钟

开始时钟、结束时钟独立，不必同时存在。不是小时表。

## V2-D4. 自然语言窗口用用户配置的脚本驱动

分组 = 用户自己加的启动器：名字 + 命令模板。产品不内置 Codex / Claude 或任何厂商 SDK。Agent 经 CLI 改计划。

## V2-D5. 目标日到期：提醒，不自动进 Plan

到了或过了目标日，To Do 里要能看出来（应用内提醒）。不会自动出现在当天 Plan。系统通知 / 闹钟不做。

## V2-D6. 时钟跟当天那次出现走

Plan / Errands 的开始、结束只属于那天的那次出现。没做完回 To Do 时，时钟留在那天历史上；下次抽到另一天要重新填。不自动按时间排序，不改日界，不产生逾期状态。

## V2-D7. 发送后立刻跑脚本

不先预览将执行的操作。Agent 经 CLI 写出的就是真的。失败时能看到脚本输出；窗口不另做整单回滚。

## V2-D8. 自然语言窗口嵌在现有本机网页里

写今天和叫 agent 在同一处。不是独立小窗。
