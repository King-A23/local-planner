# 已知背景

来源：用户本次提出的目标，以及本机已有材料。这些是发现阶段的输入，不是已定需求。

## 用户原话

要做一个本地 todo 软件，便于：

1. 每天制定计划
2. 记录长期需要完成的任务

先建立工作区，再明确产品需求。

## 本机线索

- 个人项目习惯放在 `~/Projects/personal/`。
- `~/G2_S2/Daily_Planner.pdf` 是一份空白日计划纸模，结构是：
  - 日期
  - To-Do List
  - Quick Errands（零碎差事，和主待办分开）
  - Schedule（06:00–23:00 的小时时间块）
- 使用者同时有课业、实验室研究、竞赛和多个代码项目，任务来源可能不单一。

## 暂不视为已定

- 产品名
- 客户端形态（网页 / 桌面 / 终端 / 手机）
- 数据存储格式
- 是否要小时时间块
- 是否要日历、提醒、同步
