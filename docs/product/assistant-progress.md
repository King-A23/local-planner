# 计划助手快捷键与操作过程

2026-10-01。用户确认应用内唤出快捷键和可选实时操作过程；默认继续只看结果。

- macOS ⌘⇧L，其他平台 Ctrl⇧L：打开现有助手并聚焦输入框。重复按下重新聚焦，Esc 收起；不注册全局快捷键。运行中聚焦控制区，暂停后可编辑。复用当前页面与规划草案，不自动发送、切页或创建新执行。桌面设置窗口中触发回到主窗口，隐藏或关闭的主窗口可恢复；模态窗口、文件选择器和组合输入不抢焦点。
- 设置「计划助手」增加「看模型操作过程」，关闭时显示「只看结果（推荐）」。过程包括公开步骤说明、工具操作摘要和状态；命令、输出按需展开。普通执行与规划草案共用，运行途中切换立即生效。用户向上查看时不强制滚动。
- 2026-10-01 补充：执行结束（成功、失败或停止）3 秒后自动收起操作过程，只保留可再次展开的标题；最终回复和改动回执继续显示。运行中、暂停时不自动收起，用户也可点击标题手动收起。打开已结束执行时默认收起，手动重新展开后保持展开；倒计时内点击标题会取消当次自动收起。收起期间停止过程请求，事件采集不受影响。
- 桌面偏好保存到该应用的 UserDefaults，注入两个 WebKit 窗口并即时同步，重启和端口变化仍恢复；网页版使用 localStorage。偏好不属于数据库备份。
- 直接 codex exec 使用 --json，直接 opencode run 使用 --format json；本次调用调整，不改已保存命令、模型、推理强度、权限或上下文。包装命令不改写，显式非 JSON 的 OpenCode 配置保留，提示暂不提供实时过程。
- 公共事件采用白名单：公开消息、命令、文件变更、工具调用、搜索和步骤状态；reasoning 事件不进入公共事件或最终回复。工具状态只根据收到的事件显示，操作摘要由已知 CLI 动词映射，不额外调用模型。
- GET /api/agent-runs/{id}/events?after=N 返回 items、nextSequence、truncated、source（none/codex/opencode）。事件为 sequence、itemId、kind（message/operation/status）、status、summary、可选 details；同一操作 ID 更新状态。after 非负，未知执行返回 NotFound。
- 每次执行缓冲上限 500 条、256 KiB；详情上限 8 KiB，摘要上限 2 KiB，UTF-8 按字节截断并提示。只存内存，刷新可读取，服务重启不保留。视图打开时每 500 ms 增量读取，收起或关闭选项停止请求；采集继续。
- 最终回复与中间步骤分离，既有数据差异回执仍是改动结果的依据。规划草案仍需手动保存；暂停、继续、停止、超时和进程所有权保持原语义。
- 2026-10-02 补充：助手结束后，主窗口页面右上角显示应用内通知，面板关闭时也可见。每次执行提醒一次；成功有改动时提示「已完成」，只回复和规划流程提示「已回复」，失败/停止如实提示并注明已有改动保留。通知 5 秒自动关闭，也可手动关闭；不改变焦点、页面、执行状态或过程显示偏好。首次加载已结束的历史执行不重放通知，运行中刷新后仍可收到后续完成提醒。使用礼貌级别的无障碍状态播报。
- 2026-10-02 用户澄清：主要提醒是 **macOS Dock 应用图标右上角的角标**，用于发起助手后切换到其他应用的场景。后台执行结束显示未读数量，持续保留，回到可查看的主窗口时清除；打开设置或快速录入窗口不清除。主窗口隐藏、最小化或关闭后仍监测，完成不激活应用、不弹窗。成功、失败和停止均属于需查看的结束结果，暂停不计数。原生应用独立 GET 当前执行，不依赖 WebKit 计时器；执行期间防止 App Nap 延迟监测，同时允许系统休眠。只存本次应用会话，不修改计划数据库、模型设置或通知权限；重启不重放历史终态。应用内短通知继续作为前台反馈，网页版不支持原生 Dock 角标。
